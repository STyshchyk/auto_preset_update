# CSS Editing

- Inspect only relevant selectors.
- Reuse existing CSS variables.
- Avoid duplicate selectors and conflicting styles.
- Do not introduce !important without a strong reason.
- Preserve responsive behavior.
- Avoid changing global styles for local component fixes.
- Verify desktop and mobile layouts.
