# HTML Editing

- Locate the relevant section before reading code.
- Do not read the entire HTML file by default.
- Use unique IDs, classes and semantic markers.
- Preserve DOM structure outside the requested scope.
- Do not rename IDs or classes without approval.
- Avoid unnecessary DOM restructuring.
- Preserve accessibility attributes.
- Check references to modified elements in JS and CSS.
